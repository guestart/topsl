## 技术说明

- **单文件**：HTML/CSS/JS 全部内联，无外部 CDN 依赖
- 交互：课程库筛选、平滑滚动、响应式布局、FAQ 手风琴
- 图片与免费媒体均直接热链原站（已逐一验证 98 个链接全部有效）
- **沙箱预览自适应**：应用内预览窗口是沙箱 iframe，会拦截外部链接跳转和外部图片。页面检测到处于沙箱内时会自动显示提示条，点击任意外部链接弹出"一键复制网址"小窗；图片加载失败自动换占位图。**在正常浏览器中打开（新标签页打开预览地址，或下载 index.html 双击打开）时提示条不会出现，全部链接与图片完全正常。**

## 部署

- **GitHub Pages**：把 `index.html` 传到仓库根目录（或任意静态子目录）即可，Settings → Pages 发布
- **Netlify / Vercel / 对象存储**：直接上传单文件
- 如需替换原 6 个站：删除旧目录、新站放根目录，并把旧域名 301 指向新站（GitHub Pages 仓库改名/重定向）
